# AI 全自动画 PCB 双平台一键部署文档

> **适用对象**：0 基础新手 / 嵌入式与硬件开发者  
> **覆盖平台**：嘉立创 EDA 专业版（`easyeda-agent`） + KiCad（`Konnect-EDA`）  
> **前置要求**：电脑已安装可调用 Skill / MCP 的 AI 客户端（如 **Codex**、**Claude Code**、**Antigravity** 等）并能正常访问 GitHub。

> **最省事方式（推荐）**：直接对 AI 说一句 **`去 GitHub 找 shan-eda/aipcb，帮我把里面的 AI 画板环境和 3 个 skill 一次性配好`**，AI 会自动完成下方对应步骤并安装提示词生成器 Skill。下方文档供分步手动配置或排错查阅。

---

## 一、先选平台：嘉立创 EDA 还是 KiCad？

两个平台**不需要同时装**，按你的习惯任选其一即可（熟练后也可以两个都装）：

| 对比维度 | 嘉立创 EDA 专业版（新手首选） | KiCad（开源进阶 / 本地高自由度） |
| :--- | :--- | :--- |
| **开源项目** | `zhoushoujianwork/easyeda-agent` | `Orchis-ai-LLC/Konnect-EDA` |
| **接入方式** | AI 装 Skill + 客户端导入 `.eext` 插件 | AI 装 Skill + 本地 MCP（**免装客户端插件**） |
| **核心优势** | 全中文界面、立创商城国产器件库极全、一键打样/SMT 贴片最省心 | 纯本地工程、开源免费、多层板/复杂工程自由度高、不怕云端限速 |
| **适用人群** | 刚入门画板、常在嘉立创打板贴片的同学 | 习惯本地文件管理、准备画复杂/多层板的工程师与学生 |

## 二、路线 A：嘉立创 EDA 专业版一键部署（新手推荐）

### 准备条件
- 已安装 **嘉立创 EDA 专业版**（推荐 **v3.2+ / v4.1+**；注意必须是**专业版**，不要装成标准版）。
- 打开嘉立创 EDA 专业版并登录账号，保持软件处于运行状态。

### 第 1 步：让 AI 自动安装 Skill 并吐出插件路径

打开你的 AI 客户端（Codex / Claude Code），**直接复制下面这句话发送**：

```text
去 github 找 easyeda-agent 配置为 skill 并把 eext 的路径给到我
```

> **这一步会发生什么？**  
> AI 会自动拉取 `zhoushoujianwork/easyeda-agent`、安装本地 Skill、校验运行环境，并在最后给出本机 `easyeda-agent-connector.eext` 文件的完整路径。直接复制这段路径备用。

### 第 2 步：在嘉立创 EDA 导入并启用外部交互插件

1. 回到 **嘉立创 EDA 专业版**，点击顶部菜单栏 **`高级` → `扩展管理器`**。
2. 点击弹窗左下角蓝色 **`导入`** 按钮。
3. 在弹出的文件选择窗口地址栏中，粘贴第 1 步复制的路径，找到并双击 **`easyeda-agent-connector.eext`** 完成导入。
4. 切换到左侧 **`已安装`** 标签 → 选中 **`EDA Agent Connector`** → 点击 **`配置`** → **勾选 `允许外部交互`** 并保存。

### 第 3 步：验证连接

回到 AI 对话框，发送：

```text
尝试进行连接
```

看到 AI 返回 **`已成功连接嘉立创 EDA 专业版 · 健康检查通过`**（或列出当前打开的工程/文档信息），即代表部署成功！

### 常见问题排查（嘉立创 EDA）
- **连不上 / 提示超时**：检查嘉立创 EDA 专业版是否正开着、扩展管理器里 `EDA Agent Connector` 是否已启用且勾选了 **`允许外部交互`**。
- **导入 `.eext` 失败**：确认安装的是**专业版**而非标准版；如果路径带中文或空格导致异常，可把 `.eext` 复制到纯英文目录（如 `D:\eda\`）再导入。
- **AI 找不到工程画布**：先在立创 EDA 里新建一个空白工程并打开原理图页面，再重新执行 `尝试进行连接`。

## 三、路线 B：KiCad 一键部署（开源进阶 · 免装客户端插件）

### 准备条件
- 已在本机安装 **KiCad**（建议 **KiCad 9.0 / 10.0** 官方版）。
- 建议先打开一次 KiCad 确认软件本身可以正常运行（若使用本地 IPC 联动，可在 KiCad 顶部菜单 `首选项` → `插件 / API` 中确保外部 API / IPC 服务处于开启状态）。

### 第 1 步：一句话完成 Skill + MCP + 环境配置与连通测试

打开你的 AI 客户端（Codex / Claude Code），**直接复制下面这句话发送**：

```text
去github上找Konnect-EDA配置为本机skill，同时配置kicad的环境，然后尝试连接kicad
```

> **这一步会发生什么？**  
> 1. AI 会从 `Orchis-ai-LLC/Konnect-EDA` 自动安装 6 个官方 KiCad 全流程 Skill（原理图、PCB、器件库、规则审查、制造导出等）；  
> 2. 自动配置 `konnect` MCP 服务与本机 KiCad 环境路径；  
> 3. 自动测试连通本机 KiCad（**全程无需像立创那样手动导入 `.eext` 客户端插件**）。

### 第 2 步：确认成功标志

看到 AI 回复 **`Konnect MCP 已就绪 / 已成功连接本机 KiCad`**（并能创建或读取测试工程），即代表部署完成！

### 常见问题排查（KiCad）
- **提示找不到 `kicad-cli` 或 KiCad 安装目录**：直接把你的 KiCad 安装路径（例如 `D:\KiCad\10.0\bin`）发给 AI，让它补写进配置即可。
- **MCP 刚配置完未生效**：重启一次 Codex / Claude Code 客户端，让新写入的 MCP 配置重新加载，再发送 `尝试连接 kicad`。

## 四、部署完成后的下一步（最关键细节）

环境通了之后，**不要直接丢一句大白话让 AI 瞎画**，也**不要漏掉调用 Skill**。

请配合本仓库内置的 **`pcb-prompt-helper` Skill**（详见 [`02_PCB四要素提示词系统生成指南.md`](./02_PCB四要素提示词系统生成指南.md)）：
1. 用 `pcb-prompt-helper` 把你的大白话想法整理成标准四要素工程提示词；
2. 把 **已配好的画板 Skill + 生成好的四要素提示词** 放进**同一条消息**发给 AI：
   - 嘉立创路线：`调用 easyeda-agent Skill + 粘贴四要素提示词`
   - KiCad 路线：`调用 Konnect-EDA Skill + 粘贴四要素提示词`
